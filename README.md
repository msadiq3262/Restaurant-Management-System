# Restaurant Management System

A console-based Restaurant Management System developed in C++ using Object-Oriented Programming (OOP), classes, functions, and file handling.

## Features

- Admin login
- Food menu management
- Customer management
- Table management and reservations
- Order placement, searching, and cancellation
- Billing and receipts
- Sales reports and food sales reports
- File-based data storage

## Technologies Used

- C++
- Dev-C++
- Object-Oriented Programming
- File handling

## How to Run

1. Download or clone this repository.
2. Open `RestaurantManagementSystem.dev` in Dev-C++.
3. Build the project using **Execute → Rebuild All**.
4. Run the program.
